[apache/camel@f5e3f53a3](https://github.com/apache/camel/commit/f5e3f53a3dcb1b1f4ef2f66a437fdbaf12faf0c7) (PR [#26194](https://github.com/apache/camel/pull/26194)).

[apache/camel@d207818ba](https://github.com/apache/camel/commit/d207818ba5284b3f13a61dcb257467acc5369970) (PR [#26175](https://github.com/apache/camel/pull/26175)).
- **CAMEL-24630** — `camel-core`/Kamelet: fixes a functional bug where `DefaultSupervisingRouteController` reload left duplicate internal route entries for Kamelet child routes, causing `ManagedCamelContext.getStartedRoutes()` to NPE and breaking the JBang dev console. This is a correctness/robustness fix (double route registration), not a vulnerability — no externally-triggerable security property is affected. `camel-core` is a `used_component`, but Kamelet routing/the JBang dev console is not part of our deployment; regardless, this is `NOT-SECURITY`. [apache/camel@857dc649d](https://github.com/apache/camel/commit/857dc649dd0e4c4a32bd6b5caef889b5e5166ac2) (PR [#26173](https://github.com/apache/camel/pull/26173)).
- **CAMEL-24635** — build-only: removes unused Maven-plugin-related dependencies from the reactor POMs. No runtime code change, `NOT-SECURITY`. [apache/camel@e0135790](https://github.com/apache/camel/commit/e0135790644f5f1d9e4364f082529bd6e346b7c5).
- **CAMEL-24644** — `camel-opa`: adds a producer health check that surfaces OPA-server-down as a health signal (the producer already fails closed by design when policy evaluation cannot complete; this only adds visibility). Operability improvement, `NOT-SECURITY`; `camel-opa` is not a `used_component`. [apache/camel@fae34421](https://github.com/apache/camel/commit/fae3442189680a977a9e8bcdef8fd06c17fa0766) (PR [#26191](https://github.com/apache/camel/pull/26191)).
- **CAMEL-24651** — `camel-core`/`camel-support`: fixes a regression `NullPointerException` in `ExceptionHelper.stackTraceToString()` introduced by an earlier refactor (commit `f9048eb0a822`) that dropped a null-check guard at the `LanguageHelper.exceptionStacktrace()` call site; evaluating the Simple-language expression `${exception.stacktrace}` on an exchange with no exception threw instead of returning `null`. `camel-core`/`camel-support` are `used_components`, but the vulnerable refactor this fixes was never present in our pinned 4.8.8 (4.8.8 predates `f9048eb0a822` and still carries the original null check at the call site) — the bug this patch closes could not occur on 4.8.8 in the first place. `NOT-SECURITY` (a functional NPE regression, not an attacker-controlled exploit), and **not applicable to our version regardless**. [apache/camel@3038c4b3](https://github.com/apache/camel/commit/3038c4b331f5be408df5d4b06da7a0d85d16d2bb).
- **CAMEL-24659** — `camel-jbang`: changes `camel run`'s default runtime to `jbang` and runs `--runtime=main` in a separate JVM. Feature/CLI-behavior change; `camel-jbang` is not a `used_component` (we do not run via the JBang CLI). `NOT-SECURITY`. [apache/camel@935f581a](https://github.com/apache/camel/commit/935f581a8a597cfc4210943652bb17655f958f4d) (PR [#26226](https://github.com/apache/camel/pull/26226)).
