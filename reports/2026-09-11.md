- **CAMEL-24435** — `camel-as2`: the AS2 request handler reuses one `HttpContext` for every request on a pooled connection; `RECIPIENT_ADDRESS`/`ASYNCHRONOUS_MDN` set while handling an async-MDN request were never cleared, so a later request on the same connection could have its stale attributes reused, and the MDN report or recipient address from one request could leak into the handling of a subsequent, unrelated request on the same connection. This **is** a genuine security-relevant defect (cross-request state confusion / potential misdirected-MDN information leak) — assessed `SUSPECTED` (no CVE assigned yet). However `camel-as2` is **not** in `used_components` → **NOT RELEVANT** (component not used) regardless of the defect's merit. Severity if it were in scope: *(estimated)* MEDIUM (requires a shared/pooled AS2 connection and a subsequent request racing the stale state). [apache/camel@39a25440d](https://github.com/apache/camel/commit/39a25440d2a92bacf6cfb1b64f5915b7106cb7f3) (PR [#26207](https://github.com/apache/camel/pull/26207)).
