### Reviewed and dropped (for completeness)

- **CAMEL-24061 — camel-zeebe: unauthenticated gRPC channel bypasses OAuth on 7 of 9
  `ZeebeService` operations** (PR [#24695](https://github.com/apache/camel/pull/24695),
  backport [#24701](https://github.com/apache/camel/pull/24701), merged 2026-07-15).
  - **Is this a vulnerability?** SUSPECTED — real auth-bypass fix (a raw, unauthenticated
    `ManagedChannel` was used instead of the OAuth-wrapped client for
    `cancelProcessInstance`/`publishMessage`/`completeJob`/`failJob`/`updateJobRetries`/
    `throwError`/`deployResource`), but shipped silently with no CVE/GHSA.
  - **Component in use?** `camel-zeebe` is **not** in `used_components` → **NOT-USED** →
    **verdict: NOT RELEVANT** regardless of affected-range analysis. (Note: `camel-zeebe`
    is deprecated since 4.19.0; reviewers on the PR also flagged it still uses plaintext
    channels for the token and possible token-expiry gaps remain — worth knowing if this
    component is ever adopted, but out of scope today.)
- **CAMEL-23995 — camel-kafka: `saslAuthType` silently overrides an explicit
  `securityProtocol`, producing non-working SASL configs** (PR
  [#24690](https://github.com/apache/camel/pull/24690), merged 2026-07-15).
  - **Is this a vulnerability?** NOT-SECURITY — a configuration/logic bug (forces
    `SASL_SSL` regardless of user choice, breaks Kerberos startup with external JAAS config,
    missing OAUTHBEARER/AWS-MSK-IAM callback handlers). It produces broken configs, not a
    weakened security posture, and isn't described as a security fix upstream. Dropped, but
    fingerprinted so it isn't re-flagged by future silent-fix sweeps.
- **CAMEL-23979 — expose published CVE advisories via camel-catalog / camel-jbang-mcp** (PR
  [#24573](https://github.com/apache/camel/pull/24573), commit `8cae267b`, merged
  2026-07-13).
  - **Is this a vulnerability?** NOT-SECURITY — tooling change that republishes the already
    public `camel.apache.org/security` advisory list as a JSON catalog for offline querying.
    No new vulnerability disclosed or fixed.

No new GitHub releases or tags were published in `apache/camel` since 2026-07-13 (newest tag
