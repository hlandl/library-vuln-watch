## Other commits reviewed and ruled out this run

- **CAMEL-24319** (`bb4922598c39`) — adds optional validation of the token type (`typ`) and
  authorized party (`azp`) claims to `camel-keycloak`, closing a gap where the permissions-only
  introspection path could be bypassed. This is a genuine security hardening fix upstream, but
  `camel-keycloak` is **not** in `used_components`, so it is out of scope for us regardless.
  (Related advisory `GHSA-qvc3-6q9x-95pj` / `CVE-2026-53913`, already in `state/seen.json` as
  `NOT_RELEVANT` for the same reason — see Source health / advisory-database parity check below.)
- **CAMEL-24291** (`a4dc3ea57487`) — tags SSH-based host-key-checking options
  (`camel-jsch`/`camel-ssh`) with `security="insecure:ssl"` metadata for parity with
  `camel-ftp`'s existing `strictHostKeyChecking` tagging, and removes a global `JSch.setConfig`
  call that was always overridden per-session anyway (explicitly non-behavioural per the commit
  message). Neither `camel-jsch` nor `camel-ssh` is in `used_components`; `camel-ftp` itself is
  unaffected by this change.
- **CAMEL-24317 / CAMEL-24324** (`4bf3ca7530d0`, `0089244f2d9b`) — continuation of the recurring
  "throw when `pojoRequest=true` and body is the wrong type" input-validation hardening series
  across `camel-aws2-*`/`camel-aws-*` components; `camel-aws2-eventbridge` and `camel-aws-bedrock`
  are not in `used_components`.
- **CAMEL-24268** (`2b3cb00ae9b9`) — removes a write-only, dead field left over from an earlier
  refactor (`CAMEL-24227`) in `ThrottlingInflightRoutePolicy`. Dead-code cleanup, not a fix.
- **CAMEL-24288** (`204a047bbed4`) — adds IBM watsonx.ai as a supported AI backend for the
  TUI/CLI prompt tooling. New capability, not security-relevant, and unrelated to any
  `used_components` artifact.
- **CAMEL-23932** (`1f28fb6ea21b`) — CI/repo-governance change (auto-delete stale branches,
  strengthen fork-usage policy for AI agents). Not library code.
- **CAMEL-24318** (`f434910d690e`, `134d11dd4f32`) — build tooling only (`regen.sh` improvements,
  Maven parallelization for the Jenkins deploy job).
- **CAMEL-23677** (`670620c04a0d`, `f01d41a5c824`) — enables/configures an s390x test container
  for an Artemis JMS recovery test. CI/test-infrastructure only.
- **CAMEL-23931** (`0e101544096b`) — fixes `camel.jbang.quarkus.platform.url` being ignored from
  `application.properties`. `camel-jbang` is not in `used_components`; also a functional bug fix,
  not a security fix.
- **3 dependency-bump commits** — `org.apache.fory:fory-core` (1.4.0→1.5.0), `httpclient-version`
